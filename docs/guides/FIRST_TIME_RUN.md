# First-time run

Choose the guide for the computer you are using:

- [Windows 10 or 11](FIRST_TIME_RUN_WINDOWS.md)
- [Ubuntu 22.04 or 24.04 LTS](FIRST_TIME_RUN_UBUNTU.md)

Both operating systems run the same source code, assignments, database schema,
and graders. Only the operating-system setup commands differ. A populated
`local_handoff_package` can move between Windows and Ubuntu after the source
computer has been stopped cleanly.

Do not run the same handoff package on two computers at once. The package may
contain private settings and student or research data, so never commit or
publicly share it.
