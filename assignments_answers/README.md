# Manual assignment answers

These Python files are instructor/SQA reference answers for manually testing
Assignments 1 through 8. The ROS 2 controller answers are stored in the
`assignment_5_ros2_drive_forward`, `assignment_6_ros2_obstacle_stop`,
`assignment_7_ros2_wall_stop`, and `assignment_8_ros2_turn_open_side` folders.
Students see Assignments 7 and 8 as Assignments 1 and 2 of the current course.
These files are not served by the application and do not contain hidden
grading tests.

To test an answer locally:

1. Sign in as the demo student.
2. Open the matching assignment.
3. Copy the corresponding Python file into the editor.
4. Select **Run tests**.

Keep this repository private. Students with repository access can read these
answers even though the deployed application does not expose them.
