# Manual assignment answers

These Python files are instructor/SQA reference answers for manually testing
Assignments 1 through 4. They are not served by the application and do not
contain hidden grading tests.

To test an answer locally:

1. Sign in as the demo student.
2. Open the matching assignment.
3. Copy the corresponding Python file into the editor.
4. Select **Run tests**.

Keep this repository private. Students with repository access can read these
answers even though the deployed application does not expose them.
